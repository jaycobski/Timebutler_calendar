# Timebutler Calendar - Core Project Memory

## Project Identity
- **Name**: Timebutler Calendar MVP
- **Purpose**: German holiday bridge weekend optimizer for brand awareness
- **Target**: German workers maximizing vacation days (2025-2026)
- **Business Model**: Free tool promoting TimeButler's time tracking solutions

## Constitutional Foundation (v1.1.0)
1. **User-Centric Simplicity**: No login, intuitive vacation planning
2. **Data Accuracy & Compliance**: Official German gov APIs, GDPR compliant
3. **Export & Delivery**: Email-based calendar delivery via Resend
4. **Brand Integration**: Professional TimeButler presence throughout
5. **Progressive Enhancement**: Works without JavaScript
6. **Performance & Reliability**: <2s loads, <100ms interactions, 25k users
7. **Testing Discipline**: >90% coverage, comprehensive validation

## Technical Architecture
- **Structure**: Web application (frontend/backend)
- **Languages**: TypeScript/JavaScript (Node.js 18+, ES2020+)
- **Frontend**: React/TypeScript with Next.js/Remix (SSR/SSG)
- **Backend**: Express.js/Fastify with Redis + PostgreSQL
- **Email**: Resend service with bilingual templates
- **Data**: German government APIs, 90-day retention, GDPR compliant
